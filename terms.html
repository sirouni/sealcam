The service

SealCam is an iOS original-file sealing and verification tool. You capture with this app and write a seal. The other party opens the original file in the same app to see whether the file changed after sealing, and whether a genuine copy of this app issued it.

“Sealing” means leaving a checkable credential. It does not make the file uneditable and it does not prevent retouching or rephotography. The verifier must install this app. iOS only for now.
